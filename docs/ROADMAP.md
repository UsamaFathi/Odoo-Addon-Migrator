# Roadmap

## Phase 1 — Foundation (current)
- Desktop shell + CLI
- 14.0–19.0 version planner
- Official Community source cache
- Commit-pinned source snapshot metadata
- Static source index
- Basic compatibility analyzer
- Safe copy migration engine

## Phase 2 — Real migration knowledge
- Transition packs: 14→15, 15→16, 16→17, 17→18, 18→19
- Python AST transformations
- XML/view migration rules
- manifest/assets/security rules
- JavaScript/OWL migration analysis
- source-to-source diff knowledge extraction
- before/after file diff viewer

## Phase 3 — Validation
- syntax/XML/manifest validation
- target Odoo install validation
- Docker runner + PostgreSQL
- capture tracebacks/warnings
- module test runner
- confidence levels based on what actually passed

## Phase 4 — Enterprise/local sources
- user-provided Enterprise source folder
- combined Community + Enterprise index
- no redistribution of Enterprise source

## Phase 5 — Packaging
- signed Windows installer
- background source/index updates
- versioned migration-rule packs
- optional CLI integration for CI/CD
